# История изменений

[English](CHANGELOG.md)

## 0.2.0

### Добавлено

- В настройках можно искать все команды плагинов, включая команды без назначенного сочетания клавиш. Хост может добавить в список собственные команды через `ILierneCommandSettingsSource`.
- Дополнительные представления документа можно открыть из панели вкладок, если включён `DocumentViewTabsLayout.ShowAdditionalViewsMenu`.
- Действия вкладок доступны через контекстное меню, если хост включил `LierneShell.UseTabContextMenu`.

### Изменено

- Настройки плагинов используют `FlareSettings` с поиском по категориям и изменяемой шириной панели навигации.
- В боковых группах названия вкладок сокращаются, а при нехватке места остаются иконки. За иконку можно перетащить вкладку.
- Lierne теперь требует `Flare.Components.IDE` версии 0.62.0 или выше. Обновите пакеты Flare, для которых хост фиксирует более ранние версии.

### Исправлено

- Убраны зазоры между рядами оболочки IDE.

## 0.1.1

- Flare обновлён до 0.61.1.
- Выбор вкладки и её маркеры обновляются без пересборки раскладки рабочей области.

## 0.1.0

- Первый выпуск пакетов `Lierne`, `Lierne.Abstractions` и `Lierne.Core` в NuGet для .NET 11.
- Добавлена композиция документов, окон инструментов, команд и настроек из плагинов. Оболочка IDE использует Flare и поддерживает сохранение рабочей области.
